# Win12 项目AI 辅助工具使用及披露约定

Win12 项目及 Win12 项目的依存项目均是由人类发起、开放与维护的。因此，Win12 项目的所有代码与非代码贡献、拉取请求（Pull Request）、议题（Issue）（下文简称“贡献”）的提交也均由人类完成。在本项目内（包括 Win12 Online Github组织内的本项目的依存项目）贡献代码时，请务必遵循本约定内的要求。

本文旨在规范大语言模型（LLM，亦在优势称为"人工智能"、“AI”等）使用情况的披露规则与责任划分。

## 一、导则
本项目因对技术兴趣而发起，我们希望贡献者可以在参与项目的过程中有所收获，而非绝对的功利。但在大语言模型工具辅助编程愈发盛行的当下，人们都将其视作“妙妙工具”，想实现在无人参与与监督的情况下完成工作，我们认为这是一种不负责任的，更与我们的本心相左

念及于此，有必要对项目贡献中对大语言模型工具的使用与披露作出约定，核心思想如下:

- 我们不欢迎任何不负责任的代码提交
- 您不能只负责撰写提示词，由大语言模型工具代您完成工作而不直接参与其中的任何过程，或不能理解其中内容，您的贡献将被拒绝
- 您在提交时需要明确说明使用的 LLM 模型及提供商，在部分情况下可能还需说明您所使用的 Agent 平台、使用的提示词。您同时还需要保证您已审阅过并已理解 LLM 的输出。

## 二，内容许可
鉴于当前AI训练所依赖的数据来源已超出当前版权及许可证框架的边界，本约定暂不将强制要求 LLM 输出内容与本项目许可证兼容。

但，若您的大语言模型工具输出的代码直接来自于其他项目，请确保其项目的许可证或版权与本项目兼容，并在必要时声明相关许可信息。

## 三、声明内容
当您提交的内容中存在任何由大语言模型工具生成的内容或您在提交过程中直接执行了有大语言言模型工具生成或建议的操作。您均需如实在拉取请求与议题中声明如下内容

- 使用的 LLM 以及平台
- 使用的 Agent AI 平台（如有）
- 使用的提示词
- `Assisted-by:`标签（撰写提交消息时标记），若您使用的 LLM 有自己公开的 Git 身份，需将其加入这一信息中。

您还需承诺您已理解并验证相关内容，且您的修改有人工参与而不是仅由大语言模型在无监督的情况下完成。

### 3.1 提示词
您无需在披露的提示词说明过多细节，但必须有大致的目标。若您的贡献由多轮对话完成，您仅需披露您最初的提示词

### 3.2 模型与平台
若您使用了由大语言模型驱动的智能补全功能，请声明智能补全功能的提供商（如 Jetbrains）

若您使用了本地运行的大语言模型或自托管的大语言模型请说明相关情况。

### 3.3 `Assisted-by:` 标签
在实践中，部分 Agent AI 平台会自动使用`Co-authored-by:` 标签标注自己的身份；然而处于导则中所述的原因，我们不认同其在您的代码中的“作者”身份。您应当自行配置您的 Agent 平台或使用`git commit --amend` 等方式将该标签替换为 `Assisted-by:`。

## 四、责任
若出现对于本约定的违反情况，项目维护者可能会酌情：
- 要求您补全可能遗漏的信息；
- 要求您提供完整的代理日志，并能够解释 AI 所做的更改；
- 暂时拒绝您的贡献，并建议您对贡献做出大规模修改；等

## 五、后记

希望您在享受 AI 工具带来的便利的同时，也注意对于 AI 工具的依赖程度，保留一份独自思考的能力。
