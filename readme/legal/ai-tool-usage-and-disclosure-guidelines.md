# Win12 项目 AI 辅助工具使用及披露约定

Win12 项目及其依赖的项目均是由人类发起、开发与维护的。因此，Win12 项目的所有代码与非代码贡献、拉取请求（Pull Request）、议题（Issue）（下文简称“贡献”）的提交也均由人类完成。在本项目内（包括 Win12 Online Github 组织内的本项目的依存项目）贡献代码时，请务必遵循本约定内的要求。

本文旨在规范对大语言模型（LLM，亦常被称为“人工智能”、“AI”等）的使用披露规则与责任划分。

## 一、导则
本项目因对技术的兴趣而发起，我们希望贡献者能在参与项目的过程中有所收获，而非以功利为目的。然而，在大语言模型工具辅助编程愈发盛行的当下，有人将其视作“妙妙工具”，希望在无人参与、无人监督的情况下完成全部工作。我们认为这是一种不负责任的做法，也与我们的本心相左。

念及于此，我们有必要对项目贡献中如何使用与披露大语言模型工具作出约定，核心思想如下：

- 我们不欢迎任何不负责任的代码提交；
- 您不能只负责撰写提示词，由大语言模型工具代为完成工作——如果您不直接参与任何过程，或无法理解其中内容，您的贡献将被拒绝；
- 提交时您需要明确说明所使用的 LLM 模型及提供商，部分情况下还需说明所使用的 Agent 平台与提示词；同时，您还需保证已审阅并理解 LLM 的输出。

## 二、内容许可
鉴于当前 AI 训练所依赖的数据来源已超出现有版权及许可证框架的边界，本约定暂不强制要求 LLM 输出内容与本项目许可证兼容。

但若 LLM 输出的代码直接来源于其他项目，请确保该项目的许可证或版权与本项目兼容，并在必要时声明相关许可信息。

## 三、声明内容
当您提交的内容中存在任何由大语言模型工具生成的部分，或您在提交过程中直接执行了由大语言模型工具生成或建议的操作时，均需在拉取请求与议题中如实声明以下内容：

- 所使用的 LLM 及其平台；
- 所使用的 Agent AI 平台（如有）；
- 所使用的提示词；
- `Assisted-by:` 标签（撰写提交消息时标记），若您使用的 LLM 有公开的 Git 身份，需一并注明。

此外，您还需承诺已理解并验证相关内容，且修改过程有人工参与，而非由大语言模型在无监督的情况下独立完成。

### 3.1 提示词
您无需在披露的提示词中说明过多细节，但需包含大致的目标。若您的贡献由多轮对话完成，仅需披露最初的提示词。

### 3.2 模型与平台
若您使用了由大语言模型驱动的智能补全功能，请声明该功能的提供商（如 JetBrains）。

若您使用本地运行或自托管的大语言模型，请说明相关情况。

### 3.3 `Assisted-by:` 标签
在实践中，部分 Agent AI 平台会自动使用 `Co-authored-by:` 标签标注自己的身份；然而，出于导则中所述的原因，我们不认同其作为您代码“作者”的身份。您应自行配置 Agent 平台，或使用 `git commit --amend` 等方式，将该标签替换为 `Assisted-by:`。

## 四、责任
若出现违反本约定的情况，项目维护者可能会酌情：
- 要求您补全可能遗漏的信息；
- 要求您提供完整的代理日志，并能解释 AI 所做的更改；
- 暂时拒绝您的贡献，并建议您对贡献作出大规模修改；
- 采取其他必要的处理措施。

## 五、后记

希望您在享受 AI 工具带来的便利的同时，也留意对 AI 工具的依赖程度，保留独立思考的能力。
