# Now Playing widget patch

Drop these files into the Win12 repo root:

- desktop.html
- desktop.css
- desktop.js
- module/widget.css
- module/widget.js

Changes:
- Adds a polished Now Playing widget template.
- Adds MP3 import from the local computer using `<input type="file">`.
- Plays imported MP3s locally through the browser; no upload is performed.
- Adds progress, duration, play/pause, restart, stop, toolbar/desktop support.
